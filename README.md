# DevOps Version Control Project

## 📘 Overview
This project demonstrates Git best practices used in DevOps workflows.

## 🧩 Branching Strategy
- `main` → Stable production code
- `dev` → Development integration
- `feature/*` → Individual feature development

## 🛠️ Tools Used
- Git
- GitHub

## 🔖 Git Tags
- `v1.0` → First stable version release
